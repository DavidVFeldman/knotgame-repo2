## 2. T8 — tribonacci and supergolden

| Claim of the commission | Identifier |

`N_six_le_two`, `N_zero_le_zero`).  No infeasibility report was needed.

the depth constraints in a single pass, so no layer construction is iterated
inside the kernel.

## 3. T9 — δ-transversality for `𝓑₀₁` through `x = 2/3`

Files: `TransversalityBounds.lean`, `TransversalityChecker.lean`,
`TransversalityCell.lean`, `TransversalityCertificate.lean`,
`Transversality.lean`.

| Ingredient | Identifier |
| --- | --- |
| the class, as a power series | `gval`, `gder`, truncations `gpart`, `dpart` |
| tail bounds beyond depth `D = 48` | `TransversalityBounds.lean` |
| centered-form variation bounds | `TransversalityBounds.lean` |
| the branch-and-bound checker | `cellOK` (`TransversalityChecker.lean`) |
| soundness of the checker on one cell | `cell_sound` (`TransversalityCell.lean`) |
| the 27 kernel-checked cells | `cell_01 … cell_27`, `cells`, `cells_ok`, `cells_wf` |
| the covering of the window | `exists_cell`, `cells_chain`, `cells_lastEnd` |
| **the target** | `transversality`, `transversality_deriv` |

`transversality` is exactly the commission's statement: for `c 0 = 1`,
`c i ∈ {−1,0,1}` and `x ∈ [1/2, 667/1000]`, `|g(x)| ≤ 1/1000` implies
`g′(x) < −1/1000`.  `transversality_deriv` restates it for `deriv (gval c)`,
identified with the termwise series by `hasDerivAt_gval`.

The certificate carries 27 cells, regenerated by `scripts/bnb_lean.py` (an
exact integer replica of the Lean checker) rather than taken from the enclosed
25-cell prototype decomposition; the search visits 164823 nodes.  All cell
checks are `decide +kernel`; no `native_decide`.
